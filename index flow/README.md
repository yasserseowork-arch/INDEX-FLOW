# IndexFlow — الفهرسة الجماعية لروابط جوجل

**IndexFlow** إكستنشن كروم (Manifest V3) بيطلب فهرسة روابطك جوه **Google Search Console** مباشرة — من غير أي حساب أو تسجيل، ومجاني تماماً، وبواجهة **عربية بالكامل** من اليمين لليسار.

## المميزات

- تحميل الروابط من **خريطة موقع** (XML وفهارس خرائط وgzip) أو **ملف TXT/CSV/JSON** أو لصق قائمة روابط مباشرة
- اختيار وضع الفهرسة: **الجديد فقط** أو **إعادة فهرسة** أو **الاثنين**
- تشغيل تلقائي مع أزمنة انتظار آمنة، والتعامل مع حد الحصة وإعادة المحاولة تلقائياً
- لوحة متابعة مباشرة: قيد الانتظار / جارٍ المعالجة / تم الطلب / متخطى / أخطاء، مع بحث وفلاتر وسجل نشاط عربي كامل
- أدوات Google Search Console الإضافية: فتح تقرير الصفحات وقراءة حالات التحقق الظاهرة (ومنها **Not Started**) مع اقتراحات إصلاح وتصدير CSV
- فتح تقرير Sitemaps، قراءة الخرائط المرسلة وحالاتها، وإرسال / إعادة إرسال خريطة موقع إلى الـ Property المختار
- فتح إعدادات الموقع ومحاولة طلب إعادة زحف `robots.txt` إذا كان الخيار متاحًا في ذلك الـ Property
- اختصارات اختيارية لتقارير Core Web Vitals للجوال وسطح المكتب؛ غياب التقرير أو نقص البيانات لا يمنع استخدام باقي الأدوات

## التثبيت (ملف ZIP يدوي)

1. فك ضغط `index-flow.zip` في مجلد ثابت (مثال: `Documents/index-flow`).
2. افتح `chrome://extensions` في كروم.
3. فعّل **وضع المطوّر** من الزر أعلى اليمين.
4. اضغط **Load unpacked** واختر مجلد `index-flow` بعد فك الضغط.
5. ثبّت أيقونة IndexFlow في الشريط العلوي واضغط عليها لفتح اللوحة الجانبية.

## طريقة الاستخدام

1. **الرابط** — الصق رابط خريطة الموقع، أو الصق روابط مباشرة، أو ارفع ملف TXT/CSV/JSON (رابط في كل سطر).
2. **التحميل** — IndexFlow بيقرأ الروابط ويشيل المكرر.
3. **الإعدادات** — اختر وضع الفهرسة وأزمنة الانتظار.
4. **الفهرسة** — اضغط **بدء الطابور**. سيب تبويب Search Console مفتوح؛ IndexFlow بيفتح الموقع الصح تلقائياً وبيقف بأمان لو التبويب اتقفل.

> **ملاحظة:** لازم تكون مسجّل دخول *Google Search Console* في المتصفح بحساب عنده صلاحية على الموقع. الأدوات الجديدة تفتح تقارير GSC في تبويبات منفصلة لتجنب تعطيل طابور الفهرسة.
>
> **حدود الأدوات:** الإضافة تشخّص أسباب الاستبعاد وتقترح خطوات؛ لا تستطيع تعديل ملفات الموقع أو إعدادات الخادم نيابةً عنك. أصلح السبب أولًا، ثم استخدم بدء التحقق إذا أتاح Google الإجراء. تعديل محتوى `robots.txt` يكون على الاستضافة؛ الإضافة تستطيع فقط فتح تقريره وطلب إعادة الزحف عند توفر الخيار. أما وجود Core Web Vitals وخيارات robots فيختلف من Property لآخر، لذلك التعامل معها اختياري ويعرض Google ما هو متاح فقط.

## الخصوصية

كل عمليات القراءة والتشخيص تتم محليًا داخل المتصفح. لا يوجد خادم تابع للإضافة أو إرسال بيانات إلى خدمة خارجية؛ عند طلبك، تتفاعل الإضافة مع واجهة Google Search Console وتحمّل Sitemap من موقعك مباشرة. تقارير GSC التي تقرأها تظهر داخل حسابك وتظل خاضعة لصلاحيات Google.

## اختبارات التطوير

من جذر المستودع شغّل: `node --test "index flow/tests/site-tools.test.cjs"` للتحقق من قراءة حالات التغطية وSitemaps.
